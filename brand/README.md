# ZIFT — brand

The mark for this account. One face, every surface.

> **kanıtlanmamış iddiayı denetler** · *evidence over adjectives*

---

## Source of truth

`brand/zift.svg` is the only hand-authored file here. **Every PNG in this
folder is generated by CI** ([`brand-assets.yml`](../.github/workflows/brand-assets.yml))
and must never be edited by hand — the next run will overwrite it.

To change the mark: edit the SVG, push, done. Eighteen assets regenerate.

The vector was traced from the approved raster and the trace was measured,
not eyeballed:

| Check | Value |
|---|---|
| Silhouette fidelity vs. source mask (IoU) | **0.9909** |
| Amber fidelity vs. source mask (IoU) | **0.8967** |
| Vector master size | **4.3 KB** |

## Colours

| Role | Hex | Use |
|---|---|---|
| Zift black | `#0B0B0B` | The mask itself. Never lightened. |
| Amber | `#F2CC60` | Eye slits and rim light. The only accent. |
| Surface dark | `#0D1117` | Backgrounds, matches GitHub dark. |
| Off-white | `#F5F2EA` | Wordmark, body text on dark. |

**One accent, not two.** Amber replaced the previous cyan `#00E5FF`
across every surface. A second accent colour is a second brand.

## Type

Monospace, heavy weight, wide tracking. DejaVu Sans Mono in generated
assets; JetBrains Mono where a webfont is already loaded. The wordmark is
always `ZIFT` — uppercase, never letterspaced by hand, never set in a
display or script face.

## Legibility floor

The slits are the whole identity, so CI enforces them. Every generated
icon is re-measured for amber coverage, and the build **fails** if amber
drops below 1% at 32px or larger.

Measured on the current master:

| Size | Reads as |
|---|---|
| 512 / 180 / 128 px | Full mark, drips visible |
| 48 / 32 px | Head and slits — still unmistakable |
| 16 px | Silhouette only — acceptable, not preferred |

**Minimum size: 32px.** Below that, use the silhouette knowingly.

## Clear space

Keep free space equal to the height of one eye slit on all four sides.
Nothing sits inside that margin — no text, no border, no badge.

## Do not

- Stretch, skew, or rotate the mark.
- Recolour it. Amber is not orange, gold, or yellow.
- Add a drop shadow, glow, gradient, or outline.
- Place it on a mid-tone background — it needs `#0B0B0B`, `#0D1117`, or `#F5F2EA`.
- Give it a mouth, teeth, a tongue, pupils, or a chest emblem.
- Dress it. A suited silhouette reads as an existing character and is out of bounds.
- Hand-export a PNG. Push the SVG and let CI render it.

## Site head

The workflow also owns the icon and link-preview tags in `index.html`.
They live between two markers and are rewritten on every run:

```html
<!-- zift:brand:begin - generated by brand-assets.yml -->
...
<!-- zift:brand:end -->
```

Do not edit inside that block; edit the workflow step instead. Anything
outside the markers is left untouched.

One caveat worth stating plainly: the generator commits with `[skip ci]`
to avoid recursion, so the commit that writes the head block does not
itself trigger the site test suite. The following push does.

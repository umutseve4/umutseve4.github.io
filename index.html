02 / Method

Claims need
artifacts

A project is not “done” because its README says so. Evidence should be executable, immutable, and bounded.

Tested ≠ deployed

Unit and browser checks prove code behavior in their stated environment, not live-service reachability.

Commit-pinned proof

Evidence assets point to full 40-character commit SHAs, so a later branch update cannot rewrite the claim.

Limits stay visible

Stale data, free-tier cold starts, roadmap features, and missing operational proof are stated beside the result.
